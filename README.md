# 💸 BudgetSaaS — Gestión de Gastos y Presupuesto (SaaS MVP)

BudgetSaaS es una aplicación web tipo **SaaS** para gestionar **gastos mensuales** y **presupuesto**, pensada para usuarios de LATAM.
Incluye autenticación, panel de gastos, presupuesto del mes y resumen automático.

Este proyecto fue construido como **MVP completo** listo para producción, ideal para portfolio y base para monetización futura.

---

## 🌐 Demo en producción

- **Frontend (Vercel):** https://budget-saas.vercel.app/
- **Backend API (Render):** https://budget-saas-backend.onrender.com

---

## ✨ Funcionalidades principales

- ✅ Registro y login de usuarios
- ✅ Autenticación con JWT + persistencia
- ✅ Crear, listar y eliminar gastos
- ✅ Filtro por categoría, búsqueda y orden
- ✅ Presupuesto mensual (mes actual)
- ✅ Cálculo automático (gastado / restante / % uso)
- ✅ Alertas por consumo (ok / warn / over)
- ✅ Resumen del mes y totales por categoría
- ✅ Endpoint de demo seed (carga gastos de ejemplo)
- ✅ UI moderna con Tailwind CSS (dashboard + responsive)

---

## 🧱 Stack tecnológico

### Frontend
- React + Vite
- React Router
- Context API
- Tailwind CSS

### Backend
- Node.js + Express
- MongoDB Atlas + Mongoose
